思考题

1.如果把第 2 课中 `messages.append({"role": "assistant", ...})` 那行删掉，对话会出现什么具体现象？

可能会出现回答多个问题。**❌**

**messages 是模型的全部世界，删掉 assistant 回复 = 模型失忆自己说过的话。**

2.`reset` 命令"清空记忆"的本质是什么？为什么 system 消息要重新放回去？

reset 本质是清除历史对话记录。**✅**

system 消息保证智能体回答方式不发生变化，包括语调、语气，词数量等。**✅** **保住人设**

3.为什么说"上下文窗口是 Agent 设计的第一约束"？提示：考虑长对话的成本和 4096 token 上限的模型。

太长的上下文会导致模型处理时间过长，消耗过大。并且有些语言模型也不支持很长的上下文。**⚠️**

1. **上限**：超过窗口直接报错或被静默截断 → 早期信息丢失
2. **成本**：每轮全量重发历史，长对话的累计 token 消耗接近**平方级**增长
3. **质量**：长上下文有 “lost in the middle” 问题——中部信息的召回明显差于首尾
4. **设计推论**（最重要）：Agent 不能“什么都往 context 塞”→ 必须做截断/摘要/**外置记忆按需检索**——第 4 条就是我们后面学 RAG 和记忆策略的动机，一句话：**上下文窗口小，才需要 RAG**。
